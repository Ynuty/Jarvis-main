# J.A.R.V.I.S. — локальное десктоп-приложение

Голосовой ассистент на русском для Windows. Это рабочая версия; старый веб-прототип остался в `../JARVIS.html`, разбор идеи — в `../джарвис.md`. Полное описание, установка и рецепты «как добавить» — в `README.md`.

Общение с пользователем и комментарии в коде — на русском. В начале каждого файла — шапка-комментарий.

## Запуск и проверка

- Приложение: `Запустить Джарвис.cmd`. Данные лежат в `.devhome/`: база, модели, `core.log`.
- Из терминала VS Code сначала выполнить `Remove-Item Env:ELECTRON_RUN_AS_NODE`, иначе Electron стартует как Node.
- Тесты из корня: `core\.venv\Scripts\python -m pytest`. Перед завершением правок они должны быть зелёными.
- Интерфейс: `cd app; npx tsc --noEmit; npx vite build`. Окно грузит `app/dist`, поэтому после правок в `app/` нужна пересборка.
- Оценка нейросети: `scripts/eval_llm.py`. Её прогонять после правок системного промпта.

## Устройство

- `core/jarvis/session.py` — оркестратор. Любое действие идёт только через `Ctx.call()` → `Session.call_tool()`: там политика, подтверждение и журнал. Не обходить.
- `core/jarvis/intents/rules.py` — список `INTENTS`. **Порядок важен**: узкие шаблоны ставить выше широких (`open`, `search`, `timer`, `note-add`).
- Навыки лежат в `core/jarvis/skills/`. Инструмент объявляется декоратором `@tool(...)` с уровнем риска.
- Интерфейс: `app/src`, модули на TypeScript без фреймворка, `h()` из `ui.ts`. Связь с ядром — `api.ts` (REST + WebSocket).

## Принципы, которые не нарушать

- **Приватность.** Сеть — только по явной просьбе (`network=True` + `explicit_re`). Модели качаются только из мастера (`local_files_only`). Никакой телеметрии.
- **Подтверждение.** Всё, что отправляет, удаляет или меняет данные снаружи (`external`/`danger`), подтверждается. Настройку «отключить подтверждения» не добавлять.
- **Журнал.** Каждое действие пишется в таблицу `events`; секреты из аргументов вычищаются.
- **Секреты** хранятся только в keyring (DPAPI), никогда в базе, коде или localStorage.
- **Данные ≠ команды.** Письма, страницы и документы передаются в блоке `<данные>`, ход помечается `ctx.untrusted`. Пересказ делается вызовом `dialog.plain()` без инструментов.
- **Оплату Джарвис не проводит никогда.** Рецепты магазинов не нажимают «оформить».

## Стиль ответов

Джарвис обращается «сэр» (настраивается) и отвечает коротко: 1–3 фразы для голоса. Числа и склонения — через `text/ru.py` (`plural`, `human_duration`, `words2num`).
